tipo_cobertura categórica - parque_cesped, borde_carretera, bosque_urbano (sin NA)
cos_pct numérica % 0-15 (NA permitido)
cone_index_mpa numérica MPa 0-5 (NA permitido)

El tipo de cobertura es parte del diseño del muestreo (3 coberturas × 2 manejos × 5 quintiles), por eso todos los sitios deben tenerlo y no se permiten NA. El COS no puede ser negativo y, en suelos minerales de áreas verdes, valores sobre 15% indicarían un error de digitación o un horizonte orgánico que no forma parte del muestreo. Se permiten NA porque cerca del 3% de las muestras se pierden en el laboratorio (MCAR). La resistencia a la penetración tiene como límite el rango del penetrómetro (5 MPa). Los suelos más compactados quedan como NA (MNAR), así que un valor sobre 5 MPa sería imposible en estos datos.

2. Función de validación

La función está en scripts/funciones.R, para usarla también en el informe final (index.qmd) sin copiar el código. El chunk de abajo la lee desde ese archivo y la muestra:

#funciones.R -----------------------------------------------------------------
#Funciones propias del proyecto. Se usan en index.qmd y en
# scripts/04_validacion_diccionario.qmd (un solo lugar para no duplicar código).

#validar_suelos() --------------------------------------------------------------
#Revisa los datos según el diccionario de datos (README):
# - sitio_id + profundidad_cm: cada combinación aparece una sola vez
#   (un ID repetido duplicaría filas al unir tablas con left_join)
# - tipo_cobertura: solo parque_cesped, borde_carretera o bosque_urbano, sin NA
#   (es parte del diseño del muestreo, todos los sitios deben tenerla)
# - cos_pct: entre 0 y 15 %, NA permitido (~3 % de muestras perdidas, MCAR)
# - cone_index_mpa: entre 0 y 5 MPa, NA permitido (límite del penetrómetro, MNAR)
#Entrada: una tabla con una fila por sitio x profundidad y esas columnas.
#Salida: imprime OK o FALLA para cada revisión y devuelve (de forma invisible)
# TRUE si todo está bien y FALSE si algo falla.
validar_suelos <- function(datos) {
  #estructural: duplicated() marca las filas cuyo sitio_id + profundidad ya apareció antes
  id_ok <- !any(duplicated(datos[, c("sitio_id", "profundidad_cm")]))

  #estructural: %in% da FALSE para un NA o una categoría que no está en el diseño
  cobertura_ok <- all(datos$tipo_cobertura %in%
                        c("parque_cesped", "borde_carretera", "bosque_urbano"))

  #contenido: COS entre 0 y 15 % (na.rm = TRUE ignora los NA, que están permitidos)
  cos_ok <- all(datos$cos_pct >= 0 & datos$cos_pct <= 15, na.rm = TRUE)

  #contenido: resistencia a la penetración entre 0 y 5 MPa (NA permitido)
  cone_ok <- all(datos$cone_index_mpa >= 0 & datos$cone_index_mpa <= 5,
                 na.rm = TRUE)

  #ifelse(): si la revisión dio TRUE escribe "OK"; si dio FALSE (o NA), "FALLA".
  #isTRUE() evita un error cuando la columna no existe y la revisión queda vacía.
  marca <- function(x) ifelse(isTRUE(x), "OK", "FALLA")

  cat("ID único por sitio y profundidad (estructural):", marca(id_ok),        "\n")
  cat("Cobertura válida (estructural):                ", marca(cobertura_ok), "\n")
  cat("COS 0-15 % (contenido):                        ", marca(cos_ok),       "\n")
  cat("Penetrómetro 0-5 MPa (contenido):              ", marca(cone_ok),      "\n")

  invisible(isTRUE(id_ok) & isTRUE(cobertura_ok) & isTRUE(cos_ok) & isTRUE(cone_ok))
}
validar_suelos(suelo)
ID único por sitio y profundidad (estructural): OK 
Cobertura válida (estructural):                 OK 
COS 0-15 % (contenido):                         OK 
Penetrómetro 0-5 MPa (contenido):               OK

3. Prueba con errores introducidos a propósito

Para comprobar que la función detecta problemas, se modifica una copia de los datos:

suelo_mal <- suelo
suelo_mal$tipo_cobertura[3] <- "plaza"   #categoría que no está en el diseño
suelo_mal$cos_pct[5]        <- -0.8      #COS negativo
suelo_mal$cone_index_mpa[7] <- 6.2       #sobre el límite del penetrómetro
suelo_mal <- bind_rows(suelo_mal, suelo_mal[1, ])   #fila repetida (ID duplicado)

validar_suelos(suelo_mal)
ID único por sitio y profundidad (estructural): FALLA 
Cobertura válida (estructural):                 FALLA 
COS 0-15 % (contenido):                         FALLA 
Penetrómetro 0-5 MPa (contenido):               FALLA

Con los datos simulados las cuatro revisiones dan OK. Con la copia modificada, las cuatro dan FALLA. Cuando lleguen los datos de terreno y laboratorio, esta función se puede correr antes de cada análisis.
